# Contributing to LangGraph Java

Thank you for your interest in contributing to LangGraph Java! We welcome contributions from the community.

## Getting Started

1. **Fork the repository** and clone it locally
2. **Set up your development environment**:
   - Ensure you have Java 21 or higher installed
   - Ensure you have Maven 3.6 or higher installed
3. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Workflow

1. **Make your changes** in your feature branch
2. **Build and test** your changes:
   ```bash
   mvn clean verify
   ```
3. **Ensure code quality**:
   - Follow existing code style and conventions
   - Add unit tests for new functionality
   - Add integration tests where appropriate
4. **Commit your changes** with clear, descriptive commit messages
5. **Push to your fork** and submit a pull request

## Code Style

- Follow standard Java naming conventions
- Use meaningful variable and method names
- Keep methods focused and concise
- Add JavaDoc comments for public APIs
- Maintain consistent formatting (use the formatter plugin if configured)

## Testing

- Write unit tests for all new functionality
- Ensure all tests pass before submitting a PR
- Aim for high test coverage
- Use meaningful test names that describe what is being tested

## Pull Request Process

1. Update the README.md or relevant documentation with details of changes if appropriate
2. Ensure all tests pass and the build is successful
3. Your PR will be reviewed by maintainers
4. Address any feedback or requested changes
5. Once approved, your PR will be merged

## Code of Conduct

Please be respectful and constructive in all interactions. We aim to foster an inclusive and welcoming community.

## Questions?

If you have questions or need help, please open an issue with your question.
